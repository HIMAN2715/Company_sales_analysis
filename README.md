# Company_sales_analysis

A beginner-friendly Data Analysis project using Python, NumPy, Pandas, and Matplotlib to analyze a company's sales data and generate useful business insights.

Project Overview

This project analyzes company sales data to understand:

- Total revenue
- Total units sold
- Product performance
- Region-wise revenue
- Salesperson performance
- Monthly sales trends
- High-value transactions
- Revenue distribution

The project demonstrates a basic real-world data analysis workflow:

CSV → Pandas → Data Analysis → NumPy Calculations → Matplotlib Visualization → Business Insights

Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- CSV

Tasks Performed

Pandas

- Read CSV data using "read_csv()"
- Inspect data using "head()", "tail()" and "info()"
- Check missing values
- Generate statistical summaries
- Create calculated columns
- Filter records
- Group data using "groupby()"
- Sort data
- Perform date analysis

NumPy

- Calculate total revenue using "np.sum()"
- Calculate average revenue using "np.mean()"
- Find maximum and minimum sales
- Calculate median
- Calculate standard deviation
- Convert Pandas data into NumPy arrays

Matplotlib

- Product-wise bar chart
- Region-wise revenue chart
- Monthly revenue line chart
- Product revenue pie chart
- Revenue distribution histogram
- Salesperson performance chart

Important Calculation

Revenue is calculated using:

Revenue = Units Sold × Unit Price

Example:

Units Sold = 5
Unit Price = ₹55,000

Revenue = 5 × 55,000
        = ₹2,75,000

Business Questions

The project answers questions such as:

1. What is the total revenue?
2. What is the average transaction value?
3. Which product sells the most units?
4. Which product generates the most revenue?
5. Which region generates the most revenue?
6. Which salesperson generates the most revenue?
7. What are the high-value transactions?
8. How does revenue change month by month?
9. How is revenue distributed among products?

How to Run

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/company-sales-data-analysis.git

2. Open the project

cd company-sales-data-analysis

3. Install dependencies

pip install -r requirements.txt

4. Run the analysis

python src/sales_analysis.py

The program will display the analysis results in the terminal and generate multiple visualizations.
